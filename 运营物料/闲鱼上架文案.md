## 六、风险（上架前必读）

1. **链接国内可达性是最大风险**：课程挂在 GitHub Pages（github.io），国内访问时好时坏。上架前用**手机流量（关掉 WiFi）**打开测一次，如果慢或打不开，先迁到国内可达的托管（Gitee Pages 免费、需实名审核），再上架。买家打不开 = 退款 + 差评，这个环节崩了前面全白做。
2. **闲鱼禁止虚拟商品**：商品图和描述里不能出现二维码、微信号、外链。链接只在私聊发。被系统抽中可能下架，下架就改标题（把"课程"改成"分享"）重新发。
3. **版权表述**：文案里都是自己产品的截图，无教材封面/扫描页，安全。
4. **体力活躲不掉**：每天 15 分钟（擦亮商品 + 90 秒内回消息），闲鱼算法把回复速度算进曝光权重。挂上去不管 = 没有曝光 = 没有单。
5. **配音音色非真人录音**：用的是微软晓伊神经语音（和专业数字人配音同源），不是真人录音棚。文案已写"专业配音/不是机械合成音"，如实描述，别在聊天里说成"真人录制"。
6. **emoji 显示差异**：截图里的 emoji 是彩色系统表情，不同设备渲染略有差异，但商品图用的是截好的 PNG，固定不变，不影响。
