# 孩子百科全书 v2.0 测试用例（现行回归集）

> 本用例集由需求文档 v2.0 基线逐条拆解，覆盖正常流 + 异常流 + 边界值，对应当前线上 20 主题版本。
> v1.0（5 主题 / 61 配音）用例已作废。每条用例都是可执行、可判定的「是 / 否」。

## 用例编号约定

- `TC-XX`：功能编号（对应需求文档第 3 节 9 项功能）
- `-N`：正常流用例；`-A`：异常流用例；`-B`：边界值用例

---

## TC-01 主题地图（首页 20 个主题入口）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-01-N1 | 打开首页 | 显示 20 张主题卡，顺序与 `THEME_ORDER` 一致，每张带封面和主题名 |
| TC-01-N2 | 点击任一主题卡 | 进入 `play.html?theme=<id>`，标题与该主题一致 |
| TC-01-N3 | 20 个主题逐一点击 | 每个都能进入对应主题页，无死链 |
| TC-01-B1 | 窄屏（平板竖屏）打开首页 | 主题卡自适应排布，均可点击，不溢出屏幕 |
| TC-01-B2 | 首屏加载 | 前 6 张封面 `loading="eager"`，其余 `loading="lazy"`，无白块 |

## TC-02 点选探索（每主题 4 热点）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-02-N1 | 进入主题页，点击场景内热点 | 弹出该热点知识卡，文字与 `fact` 一致 |
| TC-02-N2 | 知识卡弹出时 | 自动播放 `{themeId}-h1~h4.mp3` |
| TC-02-N3 | 点「👌 知道啦」或遮罩区 | 知识卡关闭，场景恢复可点击 |
| TC-02-N4 | 点「🔊 听一听」 | 重播当前热点配音 |
| TC-02-B1 | 连续快速点击多个不同热点 | 每个都能正常弹出，不卡住不重叠 |
| TC-02-A1 | 人为删除某条 MP3 后点热点 | 自动回退系统语音合成朗读，不静默 |

## TC-03 问答闯关（每主题 3 题）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-03-N1 | 点击问答标签 | 显示第 1 题题干 + 3 个选项，自动播放 `{themeId}-quiz-0.mp3` |
| TC-03-N2 | 答对第 1 题 | 立即播放 `fx-right-v2.mp3` 并进入第 2 题，无延迟、无锁 |
| TC-03-N3 | 3 题全对 | 显示 `#quiz-result.win`，播放 `{themeId}-badge.mp3`，徽章点亮 |
| TC-03-N4 | 答对 1 题后返回首页再进入 | 从第 2 题继续（记住玩到第几关） |
| TC-03-A1 | 答错 1 题 | 播放 `fx-wrong-v2.mp3`，可立即重选，不扣进度 |
| TC-03-A2 | 同一题连错 3 次 | 第 3 次高亮正确项并给提示文案，点对才能过 |
| TC-03-B1 | 已获得徽章后再次全对 | 提示「徽章你已经收集到啦」，收藏册数量不变 |

## TC-04 拖拽配对（每主题 4 对）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-04-N1 | 桌面鼠标拖拽图片卡到对应框 | 配对成功：卡片吸附、`.filled`、播放 `fx-match-v2.mp3` |
| TC-04-N2 | 4 对全部成功 | 显示 `#match-done.show`，播放 `fx-match-all-v2.mp3`，贴纸 +1 |
| TC-04-N3 | 平板触屏拖拽 | 触屏拖拽同样生效，反馈一致 |
| TC-04-N4 | 点选卡片再点选框 | 点选方式同样能完成配对 |
| TC-04-A1 | 拖到错误框 | 播放 `fx-match-wrong-v2.mp3` + 抖动弹回，不限次数 |
| TC-04-B1 | 已获得贴纸后再次全对 | 提示已收集，贴纸数不变 |

## TC-05 情景小故事（每主题 3 幕）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-05-N1 | 点击故事标签 | 显示第 1 幕，`#story-step` 为「1 / 3」，播放 `{themeId}-story-0.mp3` |
| TC-05-N2 | 点「下一幕 ➜」 | 进入第 2 幕，播放对应配音 |
| TC-05-N3 | 第 3 幕点「听完啦 ✓」 | 播放 `fx-story-done-v2.mp3`，解锁故事图鉴 |
| TC-05-A1 | 看到第 2 幕返回首页再进入 | 从第 1 幕重新开始（不保存中途进度） |
| TC-05-B1 | 已解锁后再次听完 | 图鉴不重复计数 |

## TC-06 收藏册（图鉴 / 徽章）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-06-N1 | 首页点「📖 我的图鉴」 | `#dex-panel.open`，按 20 主题分组显示热点条目 |
| TC-06-N2 | 首页点「🏅 我的徽章」 | `#badge-panel.open`，20 个徽章格 |

## TC-07 语音朗读（226 条配音）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-07-N1 | 默认状态 | 声音开，各玩法自动播放对应 MP3 |

| TC-07-A2 | 系统语音也不可用 | 静默不播，不弹错误提示 |

## TC-08 进度保存（本地 + 平台双存储）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-08-N1 | 得徽章 / 贴纸 / 图鉴后刷新 | 收集物不丢失 |
| TC-08-N2 | 答对 1 题后关闭浏览器重开 | 从第 2 题继续 |
| TC-08-N3 | 配对完成 2 对后重开 | 配对从头开始（预期） |
