# 孩子百科全书 v1.0 测试用例（第 4 步产物）

> 本用例集由需求文档 v1.0 基线版逐条拆解而来，覆盖正常流 + 异常流 + 边界值。每条用例都是可执行、可判定的「是 / 否」。
> **用例确认 = 需求冻结**。确认后 v1.0 期间新想法一律进变更池。

## 用例编号约定

- `TC-XX`：功能编号（对应需求文档第 3 节 9 项功能）
- `-N`：正常流用例；`-A`：异常流用例；`-B`：边界值用例

---

## TC-01 主题地图（首页 5 大主题入口）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-01-N1 | 打开首页 | 显示 5 个主题入口，每个带卡通插画和主题名（自然与动物 / 人体与健康 / 科学现象 / 日常生活 / 社会人文） |
| TC-01-N2 | 点击任一主题入口 | 进入该主题探险页，主题插画与入口一致 |
| TC-01-N3 | 5 个主题入口逐一点击 | 每个都能进入对应主题页，无死链 |
| TC-01-B1 | 窄屏（平板竖屏）打开首页 | 5 个主题入口竖排展示，均可点击，不溢出屏幕 |

## TC-02 点选探索（知识卡）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-02-N1 | 进入主题页，点击场景内热点 | 弹出该热点的知识卡，文字 ≤60 字，口语化 |
| TC-02-N2 | 知识卡弹出时 | 自动播放对应的真人感配音（assets/voice/ 中对应 MP3） |
| TC-02-N3 | 点击知识卡关闭按钮或卡片外区域 | 知识卡关闭，场景恢复可点击状态 |
| TC-02-B1 | 连续快速点击多个不同热点 | 每个都能正常弹出知识卡，不卡住不重叠 |
| TC-02-A1 | 配音文件缺失（人为删除某条 MP3 模拟） | 自动回退系统语音合成朗读，仍不静默 |

## TC-03 问答闯关（每主题 3 题）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-03-N1 | 点击问答入口 | 显示第 1 题题干（≤30 字）+ 选项，自动播放题干配音 |
| TC-03-N2 | 答对第 1 题 | 立即给鼓励反馈（配音 fx-right）并自动进入第 2 题，无 900ms 延迟 |
| TC-03-N3 | 3 题全部答对 | 获得该主题徽章，弹出祝贺配音（{theme}-badge.mp3），徽章计入收藏册 |
| TC-03-N4 | 中途退出（答对 1 题后返回首页）再进入 | 从第 2 题继续（记住玩到第几关），不从头开始 |
| TC-03-A1 | 答错第 1 题 | 播放温和错误提示音（fx-wrong），可立即重选，不扣进度 |
| TC-03-A2 | 同一题连错 3 次 | 第 3 次答错后高亮正确答案并配讲解（如「谜底是长颈鹿哦，因为……」），孩子必须点对正确答案才能过 |
| TC-03-B1 | 已获得过该主题徽章，再次全部答对 | 不重复计数，提示「这个徽章你已经收集到啦」，收藏册数量不变 |

## TC-04 拖拽配对（4 对图文配对）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-04-N1 | 桌面端用鼠标拖拽图片到对应名字 | 配对成功时卡片吸附 + 播放 fx-match 音效 |
| TC-04-N2 | 4 对全部配对成功 | 获得贴纸，播放 fx-match-all，贴纸计入收藏册 |
| TC-04-N3 | 平板触屏拖拽 | 触屏拖拽同样生效，配对成功有相同反馈 |
| TC-04-N4 | 点选图片再点选名字（备用操作） | 点选方式同样能完成配对（拖拽失手时兜底） |
| TC-04-A1 | 配错（拖到错误名字上） | 播放 fx-match-wrong 温和提示音 + 卡片弹回原位，不限次数，不惩罚 |
| TC-04-A2 | 已获得贴纸后再次全部配对成功 | 不重复计数，提示已收集，收藏册数量不变 |

## TC-05 情景小故事（3 幕）

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-05-N1 | 点击故事入口 | 显示第 1 幕画面 + 文字，自动播放该幕配音 |
| TC-05-N2 | 点击「下一幕」 | 进入第 2 幕，播放对应配音 |
| TC-05-N3 | 看完第 3 幕（最后一幕） | 获得图鉴页，播放 fx-story-done，图鉴计入收藏册 |
| TC-05-A1 | 中途退出（看到第 2 幕返回首页）再进入 | 从第 1 幕重新开始（小故事不保存中途进度，符合注意力短设定） |
| TC-05-A2 | 已获得图鉴后再次看完故事 | 不重复计数，提示已收集，收藏册数量不变 |

## TC-06 收藏册

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-06-N1 | 首页点击收藏册入口 | 显示已获得徽章 / 贴纸 / 图鉴的数量与内容 |
| TC-06-N2 | 未获得任何收集物时打开收藏册 | 显示空状态引导文案（如「还没收集到哦，快去探险吧！」），不显示空白页面 |
| TC-06-N3 | 获得部分收集物后打开 | 已获得的高亮展示，未获得的显示灰色占位 |

## TC-07 语音朗读

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-07-N1 | 默认状态 | 语音开关为开启，知识卡 / 题目 / 故事自动播放真人感配音 |
| TC-07-N2 | 点击语音开关关闭 | 所有播放停止，后续不再自动播放 |
| TC-07-N3 | 关闭语音后刷新网页 | 开关仍保持关闭状态（记住状态） |
| TC-07-A1 | 某条 MP3 文件缺失 | 自动回退系统语音合成，不静默 |
| TC-07-A2 | 系统语音合成也不可用 | 静默不播，不弹错误提示打扰孩子 |

## TC-08 进度保存

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-08-N1 | 获得徽章 / 贴纸 / 图鉴后刷新网页 | 收集物不丢失 |
| TC-08-N2 | 问答答对 1 题后关闭浏览器，重新打开 | 从第 2 题继续，不从头开始 |
| TC-08-N3 | 配对完成 2 对后关闭浏览器，重新打开 | 配对从头开始（不保存中途进度，属预期） |
| TC-08-A1 | 离线双击打开（存储不可用） | 页面正常可玩，不报错；本次进度不保存；重新在线打开时之前的进度不丢失 |

## TC-09 返回首页

| 用例 | 操作 | 预期结果 |
|---|---|---|
| TC-09-N1 | 探险页任何状态（知识卡弹出 / 问答中 / 配对中 / 故事中）点击返回首页 | 回到主题地图，首页状态正常 |
| TC-09-N2 | 返回首页后再次进入同一主题 | 进度按 TC-08 规则恢复（问答续玩、配对小故事从头） |
