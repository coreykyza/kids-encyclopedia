玩法 A · 点选探索条目2

场景区（主题封面底图）+ 4 个可点击热点按钮（emoji）
→ 点击热点：弹出知识卡（40-60 字口语化）+ 语音朗读 + 「👌 知道啦」关闭按钮

玩法 B · 问答闯关条目3

第 x / 3 题进度 → 题干（≤30 字，语音朗读）→ 3 个选项大按钮
→ 答对：鼓励语 + 立即进入下一题；答错：温和提示可重选
→ 3 题全对：弹出 🏅 徽章获取画面，进度保存条目8

玩法 C · 拖拽配对条目4

左侧 4 张图片卡（可拖拽）＋ 右侧 4 个名称框
→ 拖对：卡片吸附 + 打勾；拖错：弹回
→ 全部配对成功：弹出 ⭐ 贴纸获取画面，进度保存条目8

玩法 D · 情景小故事条目5

单幕展示区（插画位 + 故事文字）＋「下一页」大按钮，共 3 幕，逐幕语音朗读
→ 最后一幕看完：弹出 📖 图鉴页获取画面，进度保存条目8
