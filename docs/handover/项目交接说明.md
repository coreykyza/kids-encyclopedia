## 一、一句话定位

面向 **5–7 岁儿童** 的游戏化百科网页：首页是 20 张主题卡片的「世界地图」，点进去有四种玩法——点选探索（热点弹出知识卡）、问答闯关（3 题换徽章）、配对小游戏（4 组拖拽换贴纸）、情景小故事（3 幕翻页）。全部配中文真人感配音。

- 纯静态站点：HTML + CSS + 原生 JS，**无框架、无构建工具、无后端**。
- 双击 `index.html` 即可运行；部署到任意静态托管（GitHub Pages / Nginx / CDN）同样可用。
- 音频、图片全部本地文件，不依赖任何在线服务。

## 四、核心数据模型（改内容只动 `js/logic.js`）

### 4.1 主题结构

`js/logic.js` 里两个顶层常量：`THEME_ORDER`（20 个主题 id 的显示顺序）和 `THEMES`（主题内容对象）。

每个主题：

```js
{
  id: "animals",
  name: "自然与动物",          // 首页卡片名、探索页标题
  emoji: "🦁",
  image: "assets/theme-animals.jpg",
  badgeName: "动物小博士",      // 徽章名
  hotspots: [                  // 4 个热点
    { id: "h1", x: 22, y: 40,  // x/y 为场景图百分比坐标（0-100）
      title: "大象", emoji: "🐘",
      fact: "大象用长鼻子喝水、卷食物……" }
  ],
  quiz: [                      // 3 道题
    { q: "哪种动物用长鼻子喝水？",
      options: [
        { emoji: "🐘", text: "大象", correct: true },
        { emoji: "🐒", text: "猴子", correct: false },
        { emoji: "🦁", text: "狮子", correct: false }
      ] }
  ],
  match: [                     // 4 组配对
    { id: "banana", card: "🐒 小猴子", target: "🍌 香蕉" }
  ],
  story: [                     // 3 幕故事
    { emoji: "🐣", text: "小鸭子嘎嘎破壳啦！……" }
  ]
}
```

**约定**：每个主题固定 4 热点 / 3 题 / 4 配对 / 3 故事。`hotspots[].id` 必须是 `h1`~`h4`（配音文件名依赖它）。`match[].id` 是配对键，必须与 `drop-slot[data-accept]` 对应。

### 4.3 进度存档结构

```js
{
  badges:      { animals: true, ... },   // 每主题徽章是否点亮
  dex:         { animals: ["h1","h2","h3","h4","match","story"], ... },  // 已解锁的图鉴条目（每主题最多 6 条）
  stickers:    0,                        // 贴纸总数（配对全通过 +1）
  voice:       true,                     // 声音开关
  quizProgress:{ animals: 3, ... }       // 答题进行到第几题
}
```

- 存储键：`kidpedia_progress_v1`
- 纯逻辑函数（`js/logic.js` 导出）：`emptyProgress` `normalizeProgress` `saveQuizProgress` `unlockDex` `grantBadge` `countBadges` `mergeProgress` `checkAnswer` `checkMatch` `nextQuizIndex` `resolveThemeId`
- **所有进度变更都必须走这些函数**，不要就地改对象，否则字段缺失会导致渲染异常。

### 4.4 双存储策略（关键，勿简化）

`js/app.js` 的 `safeStore()` 按三级探测容量：`localStorage` → `sessionStorage` → 内存。

- `loadProgress()`：先读本地，再读平台存储，用 `mergeProgress()` 合并后回写两侧。
- `saveProgress()`：**先写本地**，再写平台存储（平台不可用时静默跳过，不影响体验）。
- `flushProgress()`：跳转/关页前带 1200ms 超时的等待，`pagehide` 事件兜底。
- 之所以这样设计：早期版本只写平台存储，用 `file://` 双击打开时配置为空 → 读写被静默跳过 → 徽章只在内存里、刷新就消失。**改动存储逻辑时务必保留本地兜底与合并语义。**

`mergeProgress` 规则：徽章、图鉴取并集；贴纸、答题进度取较大值；声音开关取逻辑与。

### 5.3 交互硬约束（改动前必读）

1. **脚本必须用经典 `<script src>`**，禁止改成 `type="module"`（否则 `file://` 双击直接失效）。
2. 答题**答对立即推进下一题**，没有 900ms 延迟、没有 `quizLock`。连点三次正确项即可通关。
3. 同一题内正确选项始终带 `data-correct="1"`；连续答错 3 次给高亮提示。
4. 热点脉冲动画用 `box-shadow`（不是 `transform`，避免与坐标定位冲突）。
5. 配对同时支持**真拖拽**与**点选兜底**（先点卡片再点框），触屏可用。
6. `play.html` 第 35 行按钮文案是「👌 知道啦」，别改。

## 七、配音系统

- 目录：`assets/voice/`
- 命名规则：
  - 热点：`{themeId}-h1.mp3` ~ `h4`
  - 题目：`{themeId}-quiz-0.mp3` ~ `quiz-2`
  - 故事：`{themeId}-story-0.mp3` ~ `story-2`
  - 徽章：`{themeId}-badge.mp3`
  - 通用音效：`fx-right-v2.mp3`（答对）`fx-wrong-v2.mp3`（答错）`fx-match-v2.mp3`（配对成功）`fx-match-wrong-v2.mp3`（配对失败）`fx-match-all-v2.mp3`（全部配对完成）`fx-story-done-v2.mp3`（故事讲完）
- 数量：20 主题 × 11 条 + 6 条音效 = **226**
- 播放：`speak(key, fallbackText)` 先播本地 mp3，`onerror` 或 `play()` 被拒时回退浏览器 `speechSynthesis`（用设备本地中文语音）。
- 重新生成（当前环境可用的合成方案）：

```bash
pip install --break-system-packages edge-tts
edge-tts --voice zh-CN-XiaoyiNeural --rate=-10% --text "要念的文本" --write-media assets/voice/xxx.mp3
```

注意 `--rate=-10%` 的等号不能省；`XiaoyouNeural` 在当前环境不可用。语速放慢 10% 是为了贴近真人讲给小孩听的感觉，改文案后请按同参数重录，否则同一主题内音色会不一致。

2026-11-24 全量重录：226 条在用配音全部用 `zh-CN-XiaoyiNeural --rate=-10%` 重新生成，文本直接取自 `js/app.js` 的朗读调用（热点为「标题。文案」，题目为题干，故事为逐幕文案，徽章为「恭喜你，答对了所有题目，获得X徽章！」）。重录后播放的录音与「加载失败回退朗读」的内容完全一致。`tools/regen-voice.py` 可复现该流程。

## 九、已知问题与待优化

1. ~~GitHub Pages 首屏图片偏慢~~ **已于本轮修复**（保留记录供交接参考）
   - 原现象：20 张封面共约 2.2 MB 一次性请求，弱网下首屏图片最长约 50 秒才显示。
   - 已做的改动：
     - 封面重压：合计 2243 KB → 1176 KB，单张 26–68 KB，尺寸 1024×576 → 860×484（安全主题 800×450）。
     - `js/app.js` 首页卡片：前 6 张 `loading="eager" fetchpriority="high"`，其余 `loading="lazy" fetchpriority="low"`，全部带 `decoding="async"` 与 `width`/`height` 防止布局抖动。
     - `css/style.css`：`.theme-card img` 增加浅色渐变骨架底色，图片未到时不再显白块。
   - 收益：首屏只需下载约 0.38 MB（前 6 张），全部 20 张仍可完整加载；实测首屏 6 张优先完成，滚动后按需补齐。
   - 若后续替换封面图，请沿用 ≤70 KB / 860×484 的标准，避免回退。
2. **平台存储依赖注入配置**：`config.js` 中 `site_id` 为空，只有在平台环境才会被注入真实值。异地部署（GitHub Pages / 自建）时会自动走本地存档，功能不受影响，但**没有跨设备同步**。
3. `js/logic.mjs` 与 `js/logic.js` 必须手工保持同步，只服务于 Node 侧断言；改 `logic.js` 时别忘了同步，`tools/verify-assets.cjs` 会检查。
4. **历史音效冗余**：`assets/voice/` 下除 226 条在用配音外，还留着 6 条早期音效（`fx-right.mp3`、`fx-wrong.mp3`、`fx-match.mp3`、`fx-match-wrong.mp3`、`fx-match-all.mp3`、`fx-story-done.mp3`），代码引用的是 `-v2` 版本，这 6 条可安全删除但当前保留作历史对照。
5. **音色异常排查（2026-11-24 已修复，务必读）**：用户反馈「答对啦，你真棒」音色奇怪，根因**不是音源文件**——是 `speak()` 的竞态：答对后先播 `fx-right-v2`，紧接着下一题的 `speak()` 把它 `pause()`，前者的 `play().catch()` 被误判为加载失败，回退到浏览器系统合成音念了这句话。已修复：
   - `speak()` 加播放序号 `audioSeq`，被打断的旧音频其 error/catch 不再触发回退；
   - 题干配音延后到鼓励语播完再播（UI 仍立即推进，连点三次通关不变）；
   - `onEnded` 带 3.2s 超时兜底，因无头浏览器/部分 WebView 的 `ended` 事件不可靠。
   - 回归测试：`tools/voice-race-test.html`（连点，断言系统音回退 0 次 + 鼓励语 mp3 加载 3 次）、`tools/voice-slow-test.html`（正常节奏，断言题干依次播出）。
   - 教训：**排查音色问题不能只看基频/文件**——基频只测音高不测音色，且"文件是对的"不等于"用户听到的是文件"。必须先插桩 `speechSynthesis.speak` 看回退是否被误触发，再动音源文件。用户说某句音色怪，第一反应应是查回退链路，不是重录。
6. **图鉴漏显示配对/故事（2026-11-24 已修复）**：旧 `renderDex()` 只遍历 `hotspots`（4 条），但存档里配对和故事解锁的是 `match`、`story` 两个 key，导致这两类图鉴**获得了却从不显示**，用户感觉"收集品没显示"。已改为每主题渲染 6 条（4 热点 + 配对达人 + 听完故事，全站 120 条），已解锁的排前面并高亮，面板顶部加「已获得 N / 总数」统计条，徽章面板同样加统计并把已获得排前面。
   - 教训：存档里的 key 和数据渲染的字段必须一一核对；"数据写进去了"不等于"界面显示了"。用户说收藏没显示，先跑 `tools/collect-e2e.html` 看四类玩法（热点/答题/配对/故事）的解锁项是否都在面板里出现。
7. **低龄适龄可读性（2026-11-24 调整）**：5-7 岁识字有限，问答选项与配对卡片/框从「emoji+文字同行小字」改为**大 emoji 单独一行 + 文字一行**（选项 emoji 56px、配对 48px），孩子看图就能选/配。未加选项朗读——选项文字（如"老虎""小猪"）无对应预生成配音，朗读只能走系统合成音，会重新引入音色不一致；题干已有晓伊配音，足够引导。

## 十、如何运行与自测

**直接运行**：双击 `index.html`，或用任意静态服务器：

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

**资产回归**（需要 Node 18+）：

```bash
node tools/verify-assets.cjs
```

从任意目录执行均可（脚本按自身位置定位仓库根）。它会检查：20 主题 × (4 热点 / 3 题 / 4 配对 / 3 故事) 结构、热点 id 规范、每题唯一正确项、20 张封面齐全且 ≤70 KB、226 条配音齐全、`js/logic.js` 与 `js/logic.mjs` 同步。预期输出 `主题 20 个 | 配音键 226 个 | 缺失 0 | 封面 20 张 | 错误 0` 与 `verify-assets ok`。退出码非 0 即回归失败。

浏览器冒烟：起本地服务后打开首页与 `play.html?theme=animals`，确认 20 张主题卡、4 个热点、4 个配对框、故事 `1 / 3`。
