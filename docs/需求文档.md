# 孩子百科全书（小小百科探险家）需求文档 v0.9（待确认）

## 1. 背景与目标

- **谁**：5-7 岁低龄孩童，对世界充满好奇心，经常向家长追问「为什么」
- **什么场景**：孩子在家使用浏览器（电脑 / 平板）自主探索，家长无需陪伴
- **什么痛点**：孩子的十万个为什么占用家长大量精力；市面儿童百科 App 要么需安装、要么偏阅读、互动性弱
- **做成什么样算成功**：第一版能在浏览器打开即玩，孩子能独立完成一次主题探险（探索 → 闯关 → 得奖励），并愿意玩第二个主题
- **项目性质**：个人项目 / 自用为主，暂无推广计划

## 2. 目标用户

- **角色**：5-7 岁孩子（唯一使用者）；家长仅负责打开网页，不参与操作
- **使用场景**：饭后 / 周末的休闲探索时间，单次 10-20 分钟
- **设备**：浏览器打开，免安装；桌面优先，兼顾平板触屏
- **认知特点**：识字量有限 → 依赖大按钮、大图标、语音朗读；注意力短 → 单任务流程、即时奖励反馈

## 3. 核心功能（v1.0 范围）

1. **主题地图**：首页展示 5 大主题入口（自然与动物 / 人体与健康 / 科学现象 / 日常生活 / 社会人文），每主题配卡通插画，点击即进入该主题探险页
2. **点选探索**：主题场景内摆放若干可点击热点（动物、器官、物品等），点击弹出童趣知识卡（每条 ≤ 60 字，口语化）
3. **问答闯关**：每主题 3 道单选题（题干 ≤ 30 字），答对立即给鼓励反馈并自动进入下一题，全部答对获得徽章
4. **拖拽配对**：每主题 1 组配对小游戏（4 对图文配对），全部配对成功获得贴纸
5. **情景小故事**：每主题 1 个 3 幕小故事，逐幕翻页，最后一幕看完获得图鉴页
6. **收集奖励**：徽章（问答）/ 贴纸（配对）/ 图鉴（故事）三类收集物，首页可随时打开收藏册查看已获得数量与内容
7. **语音朗读**：知识卡、题目、故事均支持语音播报（浏览器自带语音合成），全局开关默认开启
8. **进度保存**：收集进度仅保存在本设备（匿名、无需登录、不关联个人身份），刷新 / 重开浏览器不丢失
9. **返回首页**：探险页任何状态下可一键返回主题地图

## 4. 明确不做（v1.0 边界）

- ❌ 不做账号 / 登录 / 注册（孩子匿名使用）
- ❌ 不做多设备同步（进度仅本设备）
- ❌ 不做家长后台 / 学情报告
- ❌ 不做更多主题（第一版固定 5 个，新主题进变更池）
- ❌ 不做真实语音录音、跟读评分
- ❌ 不做付费、广告、外链跳转
- ❌ 不做 App / 小程序，仅网页
- ❌ 不接入大模型在线生成内容（内容全部内置，保证离线可控与适龄安全）

## 5. 非功能要求

- **设备 / 浏览器**：现代浏览器（Chrome / Edge / Safari 近两年版本），桌面 ≥ 1024px 与平板竖屏均可用
- **性能**：主题页打开 ≤ 2 秒（本地静态资源）
- **部署形态**：纯静态站点 + 平台数据存储（仅进度保存）；下载解压后双击 index.html 可玩（进度保存在线时生效）
- **内容安全**：全部内容由 AI 撰写并人工（用户）可审，适龄、无恐怖 / 暴力 / 广告元素
- **视觉**：明亮卡通插画风，大色块、圆角、可爱角色；主题插画由 AI 生成

## 6. 开放问题与变更池候选

- 是否增加「每日任务 / 连续打卡」激励机制（变更池）
- 是否增加主题数量或按年龄段分层内容（变更池）
- 是否需要家长查看进度的只读页面（变更池，需重新讨论存储与身份）
- 语音朗读音色 / 语速是否可调（变更池）
- 是否发布到公网供亲友孩子使用（部署阶段再定）
