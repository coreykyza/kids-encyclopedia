# 孩子百科全书（小小百科探险家）需求文档 v2.0（现行基线）

> 本文档为当前线上版本的真实基线，2026-11-24 按实际交付物重新校准。
> v1.0（5 主题 / 61 条配音）为历史草案，已被本版取代，不再作为开发依据。
> 基线确认后新想法一律进变更池，不进当前版本。

## 1. 背景与目标

- **谁**：5-7 岁低龄孩童，对世界充满好奇心，经常向家长追问「为什么」
- **什么场景**：孩子在家使用浏览器（电脑 / 平板）自主探索，家长无需陪伴
- **什么痛点**：孩子的十万个为什么占用家长大量精力；市面儿童百科 App 要么需安装、要么偏阅读、互动性弱
- **做成什么样算成功**：浏览器打开即玩，孩子能独立完成一次主题探险（探索 → 闯关 → 得奖励），并愿意玩第二个主题
- **项目性质**：个人项目 / 自用为主，暂无推广计划

## 2. 目标用户

- **角色**：5-7 岁孩子（唯一使用者）；家长仅负责打开网页，不参与操作
- **使用场景**：饭后 / 周末的休闲探索时间，单次 10-20 分钟
- **设备**：浏览器打开，免安装；桌面优先，兼顾平板触屏
- **认知特点**：识字量有限 → 依赖大按钮、大图标、语音朗读；注意力短 → 单任务流程、即时奖励反馈

## 3. 核心功能（v2.0 范围）

1. **主题地图**：首页以网格展示 **20 个主题**入口（自然与动物 / 海洋世界 / 恐龙时代 / 昆虫朋友 / 鸟类家族 / 植物王国 / 人体与健康 / 科学现象 / 太空宇宙 / 天气变化 / 四季轮回 / 日常生活 / 交通工具 / 数字乐园 / 颜色魔法 / 社会人文 / 中国地理 / 节日庆典 / 音乐与声音 / 安全小常识），每张配 860×484 主题封面，点击进入探险页
2. **点选探索**：每个主题场景内 **4 个**可点击热点（知识卡文案口语化、每条 40-60 字），点击弹出知识卡并自动朗读
3. **问答闯关**：每主题 **3 道**单选题（3 选 1），选项以**大 emoji 为主、文字为辅**（图 56px / 字 22px，适配识字有限的低龄儿童），答对立即给鼓励反馈并自动进入下一题，全部答对获得该主题徽章；同一题连错 3 次高亮正确答案并给讲解
4. **拖拽配对**：每主题 **4 对**图文配对，卡片与框同样**大 emoji + 文字两行**展示；桌面鼠标 + 平板触屏真拖拽均支持，保留「点选卡片 + 点选框」兜底操作；全部成功获得贴纸，贴纸总数不重复计数
5. **情景小故事**：每主题 **3 幕**小故事，逐幕翻页并朗读，看完最后一幕解锁图鉴条目
6. **收集奖励**：徽章（问答）/ 贴纸（配对）/ 图鉴（热点探索 + 配对 + 故事）三类收集物。图鉴每主题 **6 条**（4 热点 + 配对达人 + 听完故事），全站 **120 条**。首页「我的徽章」「我的图鉴」面板顶部显示「已获得 N / 总数」，**已获得的排最前并高亮**，一眼能看到收获；同一收集物不重复计数
7. **语音朗读**：知识卡、题目、故事、徽章、6 类通用音效共 **226 条**预生成 MP3（微软神经网络童声晓伊，`zh-CN-XiaoyiNeural`，语速 -10%），内置于 `assets/voice/`；加载失败自动回退浏览器语音合成，再失败则静默不播；全局开关默认开启且本设备持久保存
8. **进度保存**：收集进度保存到本设备（匿名、无需登录、不关联个人身份），刷新 / 重开浏览器不丢失；另保存问答已通过的题数（玩到第几关），中途退出后可续玩；配对与小故事不保存中途进度
9. **返回首页**：探险页任何状态下可一键返回主题地图，跳转前冲刷存档
10. **玩法串联与切换（v2.0.1）**：
    - 问答通关 / 配对完成后，停留约 3.5 秒看庆祝，再**自动跳到下一关**（问答→配对→故事）；也可点画面上的「去玩配对 ➜」「去听故事 ➜」立即跳
    - 每个完成态都提供「🔄 再玩一次」；故事完成后提供「🏠 回地图」
    - 已通关的主题切回问答时**保持通关画面**（不再拉回最后一题重答），仍可重玩或去下一关
    - 手动切换标签会取消待办的自动跳转，不强行把孩子拽走
    - 切换标签时停掉上一个玩法的配音、关闭知识卡，不串音、不遮挡

## 4. 明确不做（v2.0 边界）

- ❌ 不做账号 / 登录 / 注册（孩子匿名使用）
- ❌ 不做跨设备同步（平台 KV 存储仅在平台注入配置时启用，普通部署只走本地存档）
- ❌ 不做家长后台 / 学情报告
- ❌ 不做跟读评分
- ❌ 不做付费、广告、外链跳转
- ❌ 不做 App / 小程序，仅网页
- ❌ 不接入大模型在线生成内容（内容全部内置，保证离线可控与适龄安全）
- ❌ 不保存配对小游戏与情景小故事的中途进度（重进从头玩，符合注意力短的设定）

## 5. 验收标准

- **独立完成判定**：5-7 岁孩子在无家长提示下，从首页点进主题 → 点开至少 1 张知识卡 → 完成 3 题问答（允许答错重选）→ 看到徽章奖励，全程不需要阅读说明书
- **性能**：主题页打开 ≤ 2 秒（页面与插图可交互）；226 条语音按需加载，不计入该 2 秒。首屏前 6 张封面优先加载，其余懒加载
- **语音开关**：关闭后刷新网页仍保持关闭状态
- **收集物幂等**：已获得徽章 / 贴纸 / 图鉴后再次完成对应玩法，收藏册数量不变
- **数据一致性**：20 主题 × (4 热点 / 3 题 / 4 配对 / 3 故事) = 80 热点 / 60 题 / 80 配对 / 60 幕故事，配音 226 条一一对应；图鉴 20 × 6 = 120 条（4 热点 + 配对 + 故事）
- **收藏可见性**：完成配对/故事后回首页，图鉴面板须显示对应「配对达人」「听完故事」条目，徽章/图鉴面板须显示已获得数量统计且已获得项排最前（`tools/collect-e2e.html` 应 PASS）

## 6. 异常流定义

- **语音加载失败**：录音播放失败自动回退系统合成音，再失败则静默不播，不弹错误提示打扰孩子
- **存储不可用**：三级降级 `localStorage` → `sessionStorage` → 内存；本地不可用时页面仍可玩，仅进度不保存，不报错
- **问答连错 3 次**：高亮正确答案并配一句讲解，孩子点对正确答案才能过，保证不被卡死
- **配对错误**：不限次数，配错给温和提示音 + 卡片弹回，不惩罚；全部配对成功才发贴纸

## 7. 非功能要求

- **设备 / 浏览器**：现代浏览器（Chrome / Edge / Safari 近两年版本），桌面 ≥ 1024px 与平板竖屏均可用
- **部署形态**：纯静态站点，无构建步骤；双击 `index.html` 可玩（进度存本地）；支持 GitHub Pages / Nginx / CDN 任意静态托管
- **内容安全**：全部内容适龄、无恐怖 / 暴力 / 广告元素，已人工可审
- **视觉**：多邻国风格，主色 `#58CC02`，按钮 3D 厚底 + 20px 圆角，系统字体栈无外链
- **封面规格**：860×484，单张 ≤ 70 KB，合计约 1.15 MB

## 8. 变更池（v2.1 候选）

- 每日任务 / 连续打卡激励机制
- 主题数量扩充或按年龄段分层内容
- 家长查看进度的只读页面（需重新讨论存储与身份）
- 语音朗读音色 / 语速调节
- 是否发布到公网供亲友孩子使用
