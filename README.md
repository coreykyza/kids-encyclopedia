# 孩子百科全书（小小百科探险家）

面向 5-7 岁孩子的网页百科探险应用：主题地图 + 点选探索 + 问答闯关 + 拖拽配对 + 情景小故事 + 收集奖励。

## 产研流程

本项目按产研流水线执行：需求访谈 → 需求文档 → 线框图 → 高保真原型 → 需求审核 → 测试用例冻结 → 正式开发 → 测试循环 → 版本发布 → 部署上线。

- `docs/需求文档.md`：v0.9 待确认
- `docs/线框图.html`：页面骨架
- `docs/产研流程状态.md`：当前进度与决策门
- `prototype/index.html`：可交互高保真原型（浏览器直接打开）
